# TimeGraph public site

A small static website for TimeGraph, a project in development. The home page introduces the project; `crawler/` is the public information page for the planned TimeGraphBot crawler.

## Hosting

The site is designed for GitHub Pages using the repository root on the default branch. It has no build step, package manager, JavaScript, analytics, cookies, or external assets. Links between pages are relative so the site works at the GitHub Pages project URL and, later, at a custom domain.

The custom domain and DNS are not configured here.
